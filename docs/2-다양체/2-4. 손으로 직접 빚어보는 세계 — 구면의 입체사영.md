# 2-4. 손으로 직접 빚어보는 세계 — 구면의 입체사영

## 1. 구면을 덮는 가장 경제적인 방법 — 왜 6장이 아니라 2장인가?

지난 2-3장에서 우리는 위상다양체 위에 **$C^\infty$ 호환되는 차트들의 모임(매끄러운 아틀라스)** 을 부여함으로써, 관측자의 좌표계 선택에 흔들리지 않고 미적분학을 전개할 수 있는 **매끄러운 다양체(Smooth Manifold)** 의 정의를 완성했습니다. 또한 공간 전체를 덮는 한 벌의 매끄러운 아틀라스만 제시하면, 그로부터 유일한 극대 아틀라스(매끄러운 구조)가 자동적으로 결정된다는 실무 원칙도 확립했습니다.

이제 추상적인 정의에서 한 걸음 나아가, 우리가 가장 친숙하게 알고 있는 휘어진 2차원 공간인 **단위구면(Unit Sphere)**

$$ S^2 = \left\{ \text{점 } (x, y, z) \in \mathbb{R}^3 : x^2 + y^2 + z^2 = 1 \right\} $$

위에 매끄러운 구조를 손으로 직접 건설해 봅시다.

구면 $S^2$ 를 매끄러운 차트들로 덮는 첫 번째 방법은 2-1장에서 단위원 $S^1$ 에 적용했던 **반원 그래프 차트** 를 3차원으로 그대로 확장하는 것입니다. 구면 방정식 $x^2 + y^2 + z^2 = 1$ 에서 각 좌표를 나머지 두 좌표의 함수로 풀면 다음 **6개의 열린 반구(Open Hemispheres)** 차트를 얻습니다:

* 위·아래 반구: $U_\pm^z = \{ \pm z > 0 \}$, $\quad \varphi_\pm^z(\text{점 } (x, y, z)) = \text{점 } (x, y) \in B(\mathbf{0}, 1) \subset \mathbb{R}^2$
* 앞·뒤 반구: $U_\pm^x = \{ \pm x > 0 \}$, $\quad \varphi_\pm^x(\text{점 } (x, y, z)) = \text{점 } (y, z) \in B(\mathbf{0}, 1) \subset \mathbb{R}^2$
* 좌·우 반구: $U_\pm^y = \{ \pm y > 0 \}$, $\quad \varphi_\pm^y(\text{점 } (x, y, z)) = \text{점 } (x, z) \in B(\mathbf{0}, 1) \subset \mathbb{R}^2$

이 6개의 열린 반구는 $S^2$ 전체를 빈틈없이 덮으며 훌륭한 매끄러운 아틀라스를 이룹니다. 그러나 차트가 6장이나 되다 보니, 서로 겹치는 영역의 쌍만 해도 $\binom{6}{2} - 3 = 12$ 개에 달하고 제곱근 함수 $\sqrt{1 - u^2 - v^2}$ 이 계속 등장하여 대수적 다루기가 다소 번거롭습니다. (일반적인 $n$ 차원 구면 $S^n \subset \mathbb{R}^{n+1}$ 에서는 무려 $2(n+1)$ 장의 반구 차트가 필요합니다.)

여기서 수학자들은 훨씬 더 우아하고 경제적인 질문을 던졌습니다.

2-1장에서 증명했듯, 구면 $S^2$ 는 콤팩트하므로 **단 한 장의 차트** 로는 결코 덮을 수 없습니다. 그렇다면 그 바로 다음 숫자인 **'단 두 장의 차트'** 만으로 구면 $S^2$ (나아가 임의의 $n$ 차원 구면 $S^n$) 전체를 덮을 수는 없을까요?

놀랍게도 구면에서 **단 한 점(예: 북극점)** 만 빼내면, 구멍이 하나 뚫린 구면은 고무풍선을 늘여 평평하게 펼치듯 유클리드 평면 $\mathbb{R}^2$ 전체로 일대일 대응시킬 수 있습니다!

1. **북극점 $N = \text{점 } (0, 0, 1)$** 하나만 제외한 열린집합 $U_N = S^2 \setminus \{ N \}$ 을 평면 $\mathbb{R}^2$ 전체로 펼치는 첫 번째 차트 $(U_N, \varphi_N)$ 을 만듭니다.
2. 이 첫 번째 차트가 놓친 단 하나의 점인 북극점 $N$ 을 덮어 주기 위해, 이번에는 **남극점 $S = \text{점 } (0, 0, -1)$** 하나만 제외한 열린집합 $U_S = S^2 \setminus \{ S \}$ 를 평면 $\mathbb{R}^2$ 전체로 펼치는 두 번째 차트 $(U_S, \varphi_S)$ 를 만듭니다.

북극점 $N$ 과 남극점 $S$ 는 서로 다른 점이므로($N \neq S$), 두 열린집합의 합집합은 구면 전체를 남김없이 덮습니다:

$$ U_N \cup U_S = \left( S^2 \setminus \{ N \} \right) \cup \left( S^2 \setminus \{ S \} \right) = S^2 $$

이 기하학적 대응을 실제로 구현하는 고전적이고도 강력한 사상이 바로 **입체사영(Stereographic Projection)** 입니다.

---

## 2. 북극 입체사영 $\varphi_N$ 과 역변환 공식 $\varphi_N^{-1}$ 의 엄밀한 유도

입체사영의 기하학적 아이디어는 매우 직관적입니다.

3차원 공간 $\mathbb{R}^3$ 에 놓인 단위구면 $S^2$ 의 꼭대기인 **북극점 $N = \text{점 } (0, 0, 1)$** 에 작은 광원(전등)을 하나 설치했다고 상상해 보십시오. 그리고 구면의 적도를 가로지르는 수평면, 즉 $xy$ 평면($z = 0$ 인 평면 $\mathbb{R}^2$)을 스크린으로 삼습니다.

이제 북극점 $N$ 이 아닌 구면 위의 임의의 점 $p = \text{점 } (x, y, z) \in S^2 \setminus \{ N \}$ 에 대하여, 광원 $N$ 에서 출발해 점 $p$ 를 뚫고 지나가는 반직선을 그으면 이 직선은 적도 평면 $z = 0$ 과 정확히 한 점 $q = \text{점 } (u, v, 0)$ 에서 만납니다!

* 점 $p$ 가 남반구($z < 0$)에 있으면 교점 $(u, v)$ 는 적도 단위원 내부($u^2 + v^2 < 1$)에 맺히고, 남극점 $S = \text{점 } (0, 0, -1)$ 은 평면의 원점 $\text{점 } (0, 0)$ 으로 투영됩니다.
* 점 $p$ 가 적도($z = 0$) 위에 있으면 교점은 자기 자신($u = x, v = y$, $u^2 + v^2 = 1$)이 됩니다.
* 점 $p$ 가 북반구($0 < z < 1$)에 있으면 교점 $(u, v)$ 는 적도 단위원 바깥($u^2 + v^2 > 1$)으로 멀리 뻗어 나가며, 점 $p$ 가 북극점 $N$ 에 한없이 가까워질수록($z \to 1^-$) 그림자는 평면의 무한히 먼 곳($u^2 + v^2 \to \infty$)으로 뻗어 나갑니다.

이제 이 기하학적 그림자 투영을 공간해석기하학의 직선의 방정식을 이용해 한 단계도 빠짐없이 수식으로 유도해 봅시다.

### [공식 유도 1] 북극 입체사영 좌표사상 $\varphi_N : U_N \to \mathbb{R}^2$

북극점 $N = \text{점 } (0, 0, 1)$ 과 구면 위의 점 $p = \text{점 } (x, y, z) \in U_N = S^2 \setminus \{ N \}$ ($z \neq 1$) 을 지나는 $\mathbb{R}^3$ 안의 직선 $\mathbf{L}(t)$ 는 실수 매개변수 $t \in \mathbb{R}$ 를 사용하여 다음과 같이 표현됩니다:

$$ \mathbf{L}(t) = N + t(p - N) = (1 - t)N + tp $$

이를 각 성분별로 풀어서 쓰면 다음과 같습니다:

$$ \mathbf{L}(t) = \text{점 } \left( tx, \ ty, \ 1 - t + tz \right) = \text{점 } \left( tx, \ ty, \ 1 - t(1 - z) \right) $$

이 직선이 적도 평면 $z = 0$ 과 만나는 순간의 매개변수 $t$ 를 구하기 위해 세 번째 성분을 $0$ 으로 놓습니다:

$$ 1 - t(1 - z) = 0 $$

점 $p \in U_N$ 은 북극점이 아니므로 $z \neq 1$, 즉 $1 - z \neq 0$ 입니다. 따라서 양변을 $1 - z$ 로 나누면 교점에서의 매개변수 $t$ 가 유일하게 결정됩니다:

$$ t = \frac{1}{1 - z} $$

이 $t$ 값을 직선 $\mathbf{L}(t)$ 의 첫 번째와 두 번째 성분에 대입하면, 적도 평면 $z = 0$ 위에 맺히는 교점의 평면 좌표 $\text{점 } (u, v) \in \mathbb{R}^2$ 를 얻습니다!

$$ \varphi_N\left( \text{점 } (x, y, z) \right) = \text{점 } (u, v) = \text{점 } \left( \frac{x}{1 - z}, \ \frac{y}{1 - z} \right) $$

이 사상 $\varphi_N : U_N \to \mathbb{R}^2$ 를 **북극 입체사영(Stereographic Projection from the North Pole)** 이라고 부릅니다. 정의역 $U_N$ 안에서는 분모 $1 - z$ 가 결코 $0$ 이 되지 않으므로, $\varphi_N$ 은 연속사상입니다.

---

### [공식 유도 2] 북극 입체사영의 역변환 사상 $\varphi_N^{-1} : \mathbb{R}^2 \to U_N$

이번에는 거꾸로 적도 평면 위의 임의의 점 $(u, v) \in \mathbb{R}^2$ 가 주어졌을 때, 이 그림자를 만든 구면 위의 원래 점 $p = \text{점 } (x, y, z) \in U_N$ 을 복원하는 역변환 공식 $\varphi_N^{-1}$ 을 유도해 봅시다.

1. 입체사영 공식 $u = \frac{x}{1 - z}$ 와 $v = \frac{y}{1 - z}$ 로부터 다음이 성립합니다:
   $$ x = u(1 - z), \qquad y = v(1 - z) $$
2. 따라서 $z$ 좌표만 $u, v$ 의 함수로 구해 내면 $x$ 와 $y$ 는 즉시 결정됩니다! 점 $(x, y, z)$ 가 단위구면 $S^2$ 위의 점이라는 조건 $x^2 + y^2 + z^2 = 1$ 에 위 식을 대입하거나, 평면 원점으로부터의 거리의 제곱 $u^2 + v^2$ 을 계산해 봅시다:
   $$ u^2 + v^2 = \frac{x^2 + y^2}{(1 - z)^2} $$
3. 구면의 방정식 $x^2 + y^2 + z^2 = 1$ 로부터 분자의 $x^2 + y^2$ 은 $1 - z^2 = (1 - z)(1 + z)$ 로 인수분해됩니다!
   $$ u^2 + v^2 = \frac{1 - z^2}{(1 - z)^2} = \frac{(1 - z)(1 + z)}{(1 - z)^2} $$
4. $z \neq 1$ 이므로 분모와 분자에서 $(1 - z)$ 를 약분하면 놀랍도록 간단한 관계식을 얻습니다:
   $$ u^2 + v^2 = \frac{1 + z}{1 - z} $$
5. 이제 이 식을 $z$ 에 관하여 풀어 줍시다:
   $$ (u^2 + v^2)(1 - z) = 1 + z \quad \implies \quad (u^2 + v^2) - 1 = z\left( u^2 + v^2 + 1 \right) $$
   따라서 구면 위의 높이 $z$ 와 $1 - z$ 는 다음과 같이 결정됩니다:
   $$ z = \frac{u^2 + v^2 - 1}{u^2 + v^2 + 1}, \qquad 1 - z = 1 - \frac{u^2 + v^2 - 1}{u^2 + v^2 + 1} = \frac{2}{u^2 + v^2 + 1} $$
6. 마지막으로 $1 - z = \frac{2}{u^2 + v^2 + 1}$ 을 1단계의 $x = u(1 - z)$, $y = v(1 - z)$ 에 대입하면 역변환 공식이 완성됩니다!

$$ \varphi_N^{-1}\left( \text{점 } (u, v) \right) = \text{점 } \left( \frac{2u}{u^2 + v^2 + 1}, \ \frac{2v}{u^2 + v^2 + 1}, \ \frac{u^2 + v^2 - 1}{u^2 + v^2 + 1} \right) $$

이 역변환 사상 $\varphi_N^{-1} : \mathbb{R}^2 \to U_N$ 을 살펴보십시오:
* 모든 실수 $(u, v) \in \mathbb{R}^2$ 에 대하여 분모 $u^2 + v^2 + 1 \ge 1 > 0$ 이므로 분모가 $0$ 이 되는 일이 절대 없으며, 세 성분 모두 다항식의 나눗셈(유리함수)이므로 평면 $\mathbb{R}^2$ 전체에서 연속(나아가 $C^\infty$)입니다.
* 또한 세 번째 성분이 $z = \frac{u^2 + v^2 - 1}{u^2 + v^2 + 1} < 1$ 이므로 함숫값은 언제나 북극점 $N$ 을 제외한 영역 $U_N$ 안에 정확히 들어오며, 제곱의 합이 $\frac{4(u^2+v^2) + (u^2+v^2-1)^2}{(u^2+v^2+1)^2} = \frac{(u^2+v^2+1)^2}{(u^2+v^2+1)^2} = 1$ 이므로 정확히 단위구면 위의 점이 됩니다.

이로써 $\varphi_N : U_N \to \mathbb{R}^2$ 는 전단사 위상동형사상이며, 순서쌍 **$(U_N, \varphi_N)$ 은 구면 $S^2$ 의 완벽한 첫 번째 좌표 차트** 임이 증명되었습니다!

## 3. 남극 입체사영 $\varphi_S$ 와 전이 사상 $\varphi_S \circ \varphi_N^{-1}$ 의 직접 계산

첫 번째 차트 $(U_N, \varphi_N)$ 이 덮지 못한 유일한 점인 북극점 $N = \text{점 } (0, 0, 1)$ 을 덮기 위해, 이번에는 **남극점 $S = \text{점 } (0, 0, -1)$** 에 광원을 설치하고 구면 위의 점 $p = \text{점 } (x, y, z) \in U_S = S^2 \setminus \{ S \}$ ($z \neq -1$) 를 적도 평면 $z = 0$ 에 투영합니다.

### [공식 유도 3] 남극 입체사영 차트 $(U_S, \varphi_S)$

북극 입체사영에서 $z$ 의 부호만 $-z$ 로 바꾸면(즉, $1 - z$ 자리에 $1 - (-z) = 1 + z$ 를 넣으면), 남극 입체사영 $\varphi_S : U_S \to \mathbb{R}^2$ 와 그 역변환 $\varphi_S^{-1} : \mathbb{R}^2 \to U_S$ 공식이 즉시 얻어집니다:

$$ \varphi_S\left( \text{점 } (x, y, z) \right) = \text{점 } (\tilde{u}, \tilde{v}) = \text{점 } \left( \frac{x}{1 + z}, \ \frac{y}{1 + z} \right) $$

$$ \varphi_S^{-1}\left( \text{점 } (\tilde{u}, \tilde{v}) \right) = \text{점 } \left( \frac{2\tilde{u}}{\tilde{u}^2 + \tilde{v}^2 + 1}, \ \frac{2\tilde{v}}{\tilde{u}^2 + \tilde{v}^2 + 1}, \ \frac{1 - (\tilde{u}^2 + \tilde{v}^2)}{\tilde{u}^2 + \tilde{v}^2 + 1} \right) $$

이 두 번째 차트 $(U_S, \varphi_S)$ 에서 북극점 $N = \text{점 } (0, 0, 1)$ 은 평면의 원점

$$ \varphi_S\left( \text{점 } (0, 0, 1) \right) = \text{점 } \left( \frac{0}{1 + 1}, \ \frac{0}{1 + 1} \right) = \text{점 } (0, 0) \in \mathbb{R}^2 $$

으로 아주 매끄럽게 투영됩니다!

---

### [핵심 계산] 두 차트 사이의 전이 사상 $\tau_{N, S} = \varphi_S \circ \varphi_N^{-1}$

이제 구면 $S^2$ 를 덮는 두 장의 차트 $(U_N, \varphi_N)$ 과 $(U_S, \varphi_S)$ 가 서로 **매끄럽게($C^\infty$) 호환되는지** 확인하기 위해, 두 차트 사이의 **전이 사상(Transition Map)** 을 직접 계산해 봅시다!

1. **겹치는 영역 $U_N \cap U_S$ 와 전이 사상의 정의역·공역:**
   두 차트의 좌표 근방이 겹치는 영역은 북극점 $N$ 과 남극점 $S$ 두 점을 모두 제외한 구면입니다:
   $$ U_N \cap U_S = S^2 \setminus \{ N, S \} = \left\{ \text{점 } (x, y, z) \in S^2 : z \neq \pm 1 \right\} $$
   북극 차트 $\varphi_N$ 에서 남극점 $S = \text{점 } (0, 0, -1)$ 은 평면의 원점 $\text{점 } (0, 0)$ 에 대응하므로, $U_N \cap U_S$ 를 $\varphi_N$ 으로 보낸 상은 **원점을 제외한 평면 전체** 가 됩니다:
   $$ \varphi_N\left( U_N \cap U_S \right) = \mathbb{R}^2 \setminus \left\{ \text{점 } (0, 0) \right\} $$
   마찬가지로 남극 차트 $\varphi_S$ 에서는 북극점 $N$ 이 원점 $\text{점 } (0, 0)$ 에 대응하므로, 공역 역시 원점을 제외한 평면 전체입니다:
   $$ \varphi_S\left( U_N \cap U_S \right) = \mathbb{R}^2 \setminus \left\{ \text{점 } (0, 0) \right\} $$

2. **전이 사상 $\left( \varphi_S \circ \varphi_N^{-1} \right)(\text{점 } (u, v))$ 의 대수적 계산:**
   원점이 아닌 임의의 평면 점 $\text{점 } (u, v) \in \mathbb{R}^2 \setminus \{ \text{점 } (0, 0) \}$ 에 대하여, $\varphi_N^{-1}(\text{점 } (u, v)) = \text{점 } (x, y, z)$ 를 남극 사영 $\varphi_S(\text{점 } (x, y, z)) = \text{점 } \left( \frac{x}{1+z}, \frac{y}{1+z} \right)$ 에 대입해 봅시다.
   물론 앞서 구한 $\varphi_N^{-1}$ 공식을 직접 대입해도 되지만, 훨씬 더 명쾌한 지름길이 있습니다!
   북극 사영 좌표 $(u, v)$ 와 남극 사영 좌표 $(\tilde{u}, \tilde{v})$ 의 곱과 비를 비교해 보십시오:
   $$ u^2 + v^2 = \frac{x^2 + y^2}{(1 - z)^2} = \frac{1 - z^2}{(1 - z)^2} = \frac{1 + z}{1 - z} $$
   따라서 첫 번째 성분의 비를 계산하면 놀라운 소거가 일어납니다:
   $$ \tilde{u} = \frac{x}{1 + z} = \frac{x}{1 - z} \cdot \frac{1 - z}{1 + z} = \frac{u}{u^2 + v^2} $$
   마찬가지로 두 번째 성분 역시 다음과 같이 얻어집니다:
   $$ \tilde{v} = \frac{y}{1 + z} = \frac{y}{1 - z} \cdot \frac{1 - z}{1 + z} = \frac{v}{u^2 + v^2} $$

결국 북극 차트에서 남극 차트로 좌표를 번역하는 전이 사상 $\tau_{N, S} = \varphi_S \circ \varphi_N^{-1} : \mathbb{R}^2 \setminus \{ \mathbf{0} \} \to \mathbb{R}^2 \setminus \{ \mathbf{0} \}$ 은 단 한 줄의 수식으로 정리됩니다!

$$ \left( \varphi_S \circ \varphi_N^{-1} \right)\left( \text{점 } (u, v) \right) = \text{점 } (\tilde{u}, \tilde{v}) = \text{점 } \left( \frac{u}{u^2 + v^2}, \ \frac{v}{u^2 + v^2} \right) $$

대칭성에 의해 반대 방향의 전이 사상 $\tau_{S, N} = \varphi_N \circ \varphi_S^{-1}$ 도 정확히 똑같은 수식 $\text{점 } (\tilde{u}, \tilde{v}) \mapsto \text{점 } \left( \frac{\tilde{u}}{\tilde{u}^2 + \tilde{v}^2}, \frac{\tilde{v}}{\tilde{u}^2 + \tilde{v}^2} \right)$ 로 주어집니다.

---

### [기하학적 의미와 매끄러움의 확인]

이 전이 사상 $\text{점 } (\tilde{u}, \tilde{v}) = \text{점 } \left( \frac{u}{u^2+v^2}, \frac{v}{u^2+v^2} \right)$ 이 지닌 두 가지 핵심 성질을 음미해 보십시오.

1. **완벽한 $C^\infty$ 미분동형사상:**
   전이 사상의 정의역은 원점이 제거된 열린집합 $\mathbb{R}^2 \setminus \{ \text{점 } (0, 0) \}$ 입니다. 이 영역 안에서는 모든 점 $(u, v)$ 에 대해 분모 $u^2 + v^2 > 0$ 이므로, 분모가 $0$ 이 되는 특이점이 전혀 없습니다! 따라서 두 성분함수 $\frac{u}{u^2+v^2}$ 와 $\frac{v}{u^2+v^2}$ 는 몇 번이고 끝없이 편미분할 수 있는 **$C^\infty$ 유리함수** 이며, 전이 사상 $\varphi_S \circ \varphi_N^{-1}$ 은 완벽한 **$C^\infty$ 미분동형사상** 입니다.
2. **단위원 반전 변환 (Circle Inversion):**
   평면 점 $\mathbf{u} = \text{점 } (u, v)$ 를 극좌표 $(r, \theta)$ 로 나타내면($r = \sqrt{u^2 + v^2} > 0$), 전이 사상은 편각 $\theta$ 는 그대로 유지한 채 원점으로부터의 거리 $r$ 만 역수 $\tilde{r} = \frac{1}{r}$ 로 뒤집는 **반전 변환(Inversion)** 입니다:
   $$ \tilde{r} = \sqrt{\tilde{u}^2 + \tilde{v}^2} = \frac{1}{\sqrt{u^2 + v^2}} = \frac{1}{r} $$
   * 적도($r = 1$) 위의 점들은 두 지도에서 똑같이 단위원($\tilde{r} = 1$) 위에 놓입니다.
   * 북극 지도에서 원점 바깥 멀리($r \to \infty$, 즉 북극점 근처)로 뻗어 나가던 점들은, 남극 지도로 갈아타는 순간 원점 근처($\tilde{r} = 1/r \to 0$)로 얌전하게 모여듭니다!

## 4. $n$ 차원 단위구면 $S^n$ 으로의 일반화와 매끄러운 다양체 증명

방금 2차원 구면 $S^2$ 에서 수행한 모든 기하학적 구성과 대수적 계산은 차원 $n$ 에 아무런 제약을 받지 않습니다!

$(n+1)$ 차원 유클리드 공간 $\mathbb{R}^{n+1}$ 안에 놓인 **$n$ 차원 단위구면($n$-dimensional Unit Sphere)**

$$ S^n = \left\{ \text{점 } (\mathbf{x}, z) = \text{점 } (x^1, \dots, x^n, z) \in \mathbb{R}^n \times \mathbb{R} : \|\mathbf{x}\|^2 + z^2 = 1 \right\} $$

에 대하여, 북극점 $N = \text{점 } (\mathbf{0}, 1)$ 과 남극점 $S = \text{점 } (\mathbf{0}, -1)$ 을 사용하여 완전히 동일한 정리를 확립할 수 있습니다.

### [정리] $n$ 차원 단위구면 $S^n$ 의 표준 매끄러운 다양체 구조

임의의 자연수 $n \ge 1$ 에 대하여, $n$ 차원 단위구면 $S^n \subset \mathbb{R}^{n+1}$ 위의 두 차트:

1. **북극 입체사영 차트 $(U_N, \varphi_N)$:** $U_N = S^n \setminus \{ N \}$,
   $$ \varphi_N\left( \text{점 } (\mathbf{x}, z) \right) = \mathbf{u} = \frac{\mathbf{x}}{1 - z} \in \mathbb{R}^n, \qquad \varphi_N^{-1}(\mathbf{u}) = \text{점 } \left( \frac{2\mathbf{u}}{\|\mathbf{u}\|^2 + 1}, \ \frac{\|\mathbf{u}\|^2 - 1}{\|\mathbf{u}\|^2 + 1} \right) $$
2. **남극 입체사영 차트 $(U_S, \varphi_S)$:** $U_S = S^n \setminus \{ S \}$,
   $$ \varphi_S\left( \text{점 } (\mathbf{x}, z) \right) = \tilde{\mathbf{u}} = \frac{\mathbf{x}}{1 + z} \in \mathbb{R}^n, \qquad \varphi_S^{-1}(\tilde{\mathbf{u}}) = \text{점 } \left( \frac{2\tilde{\mathbf{u}}}{\|\tilde{\mathbf{u}}\|^2 + 1}, \ \frac{1 - \|\tilde{\mathbf{u}}\|^2}{\|\tilde{\mathbf{u}}\|^2 + 1} \right) $$

로 이루어진 모임 $\mathcal{A}_{\text{stereo}} = \left\{ (U_N, \varphi_N), \, (U_S, \varphi_S) \right\}$ 는 $S^n$ 위의 **매끄러운($C^\infty$) 아틀라스** 이며, 따라서 $S^n$ 은 $n$ 차원 매끄러운 다양체이다.

**증명**

1. **위상다양체 조건:**
   $S^n$ 은 하우스도르프이고 제2 가산인 유클리드 공간 $\mathbb{R}^{n+1}$ 의 부분공간이므로 하우스도르프 조건과 제2 가산성을 만족합니다(1-8장). 또한 $\varphi_N : U_N \to \mathbb{R}^n$ 과 $\varphi_S : U_S \to \mathbb{R}^n$ 은 모두 양방향 연속인 전단사 사상(위상동형사상)이며 $U_N \cup U_S = S^n$ 이므로, $S^n$ 은 $n$ 차원 위상다양체입니다.
2. **전이 사상의 $C^\infty$ 호환성:**
   겹치는 영역 $U_N \cap U_S = S^n \setminus \{ N, S \}$ 의 상은 $\varphi_N(U_N \cap U_S) = \varphi_S(U_N \cap U_S) = \mathbb{R}^n \setminus \{ \mathbf{0} \}$ 이며, 3절과 동일한 계산에 의해 양방향 전이 사상은
   $$ \left( \varphi_S \circ \varphi_N^{-1} \right)(\mathbf{u}) = \frac{\mathbf{u}}{\|\mathbf{u}\|^2} = \text{점 } \left( \frac{u^1}{\sum_{i=1}^n (u^i)^2}, \ \dots, \ \frac{u^n}{\sum_{i=1}^n (u^i)^2} \right) $$
   으로 주어집니다. 정의역 $\mathbb{R}^n \setminus \{ \mathbf{0} \}$ 의 모든 점에서 분모 $\|\mathbf{u}\|^2 = \sum_{i=1}^n (u^i)^2 > 0$ 이므로, 각 성분함수는 무한 번 편미분 가능한 $C^\infty$ 함수입니다.

따라서 $\mathcal{A}_{\text{stereo}}$ 는 매끄러운 아틀라스이며, 2-3장의 극대 아틀라스 정리에 의해 $S^n$ 위에 유일한 매끄러운 구조(표준 매끄러운 구조)를 부여합니다. $\blacksquare$

### [연습문제 / 사유 과제] 반구 사영 아틀라스와 입체사영 아틀라스의 동치성 확인

2-1장과 2-3장에서 우리는 단위원 $S^1$ (또는 구면 $S^n$) 위에 **반원/반구 그래프 차트들로 이루어진 아틀라스 $\mathcal{A}_{\text{graph}}$** 를 구성했고, 이번 장에서는 **2개의 입체사영 차트로 이루어진 아틀라스 $\mathcal{A}_{\text{stereo}}$** 를 구성했습니다.

1. $S^2$ 의 위쪽 열린 반구 차트 $\left( U_+^z, \varphi_+^z \right)$ ($U_+^z = \{ z > 0 \}$, $\varphi_+^z(\text{점 } (x, y, z)) = \text{점 } (x, y) \in B(\mathbf{0}, 1)$) 와 남극 입체사영 차트 $(U_S, \varphi_S)$ 가 겹치는 영역 $U_+^z \cap U_S = U_+^z$ 에서, 두 차트 사이의 전이 사상
   $$ \left( \varphi_S \circ \left( \varphi_+^z \right)^{-1} \right)\left( \text{점 } (x, y) \right) = \text{점 } \left( \frac{x}{1 + \sqrt{1 - x^2 - y^2}}, \ \frac{y}{1 + \sqrt{1 - x^2 - y^2}} \right) $$
   을 유도하고, 이 사상이 열린 단위원판 $B(\mathbf{0}, 1) = \{ x^2 + y^2 < 1 \}$ 위에서 왜 $C^\infty$ 미분동형사상인지 설명하십시오.
2. 이를 통해 반구 그래프 아틀라스 $\mathcal{A}_{\text{graph}}$ 와 입체사영 아틀라스 $\mathcal{A}_{\text{stereo}}$ 가 서로 매끄럽게 호환되며, 2-3장의 정리에 의해 $S^n$ 위에 **완전히 동일한 극대 아틀라스(매끄러운 구조)** 를 정의함을 확인하십시오.

## 5. 다음 장을 향한 질문 — 이제 이 매끄러운 무대 위에서 '함수'와 '사상'을 어떻게 다룰 것인가?

우리는 2-1장부터 2-4장까지 달려오며, 국소 좌표 차트 $(U, \varphi)$, 전이 사상 $\psi \circ \varphi^{-1}$, 매끄러운 아틀라스 $\mathcal{A}$ 를 차례로 세우고, 가장 대표적인 휘어진 공간인 $n$ 차원 구면 $S^n$ 이 단 두 장의 입체사영 차트로 덮이는 완벽한 **매끄러운 다양체** 임을 손으로 직접 증명했습니다.

드디어 미적분학이 작동할 수 있는 휘어진 무대(매끄러운 다양체 $M$)가 완성된 것입니다!

그렇다면 이제 무대 위에서 펼쳐질 본론으로 들어갈 차례입니다.

1. 지구 표면($S^2$) 각 지점의 기온이나 대기압을 나타내는 스칼라 함수 $f: S^2 \to \mathbb{R}$ 가 **"구면 전체에서 매끄럽다($C^\infty$)"** 는 것은 어떻게 정의하고 어떻게 계산해야 할까요?
2. 한 매끄러운 다양체 $M$ (예: 단위원 $S^1$ 또는 토러스 $T^2$)에서 다른 매끄러운 다양체 $N$ (예: 구면 $S^2$)으로 가는 일반 사상 $F: M \to N$ 이 **"매끄러운 사상(Smooth Map)"** 이라는 것은 어떻게 판별할까요?
3. 나아가 1-5장에서 위상공간의 동등성을 **위상동형사상(Homeomorphism)** 으로 규정했던 것처럼, 두 매끄러운 다양체가 미분기하학적으로 완벽히 똑같은 공간임을 뜻하는 **미분동형사상(Diffeomorphism)** 은 어떻게 정의될까요?
